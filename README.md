# 远见·企业出海助手

面向中国小家电出海业务的合规准备工作台：把**企业研究档案、产品与目标市场登记、法规合规初筛、HS 候选与税费阶段测算、政策新闻雷达、千问辅助建议**连接成一条**向导主线**，产出一份可追溯的综合报告。

纯静态网站（无后端、无数据库、无内置密钥），可直接部署在 GitHub Pages；本机双击 `index.html` 也能使用核心功能。

> **本仓库为第二版 R1**：基于原仓库 `LJH131313-a/vision-overseas` 的只读基线 `81604dc`，整合二次交付（zky 税费修复与政策原文、yjh 首页与研究档案、wjy 地图雷达）。
> 硬性原则：**第一版有的，第二版必须有；第二版的所有修改都是在第一版基础上的加法**——由 `tests/v1-superset.test.mjs` 超集门禁强制校验，回归即中止发布。
> 线上地址：**https://ljh131313-a.github.io/vision-overseas-R1/**

## 使用动线（左侧栏向导）

首页（封面 + 四步上手）→ ① 项目与产品 → ② 合规初筛 → ③ HS 与税费 → ④ 新闻雷达（可选）→ ⑤ 千问建议 → ⑥ 综合报告；侧栏每项带完成状态点，另可直达「产品研究档案」「政策资料库」两个子页，顶部「上手指南」说明整个工作台怎么用、哪些资料影响哪些结果。

1. **项目与产品**：可选从企业案例一键带入（小熊电器 / 石头科技公开研究档案，含待核实参数与研究路线声明；国内型号不自动当作出口型号）；登记项目、目的地与品类。目的地按服务档位分组；品类卡片直接显示该「品类 × 目的地」能做到哪一步。**关键事实按需追问**：只显示影响当前判断的问题（引擎实时反推），其余参数收入选填折叠区。研究档案 16 款型号可按品牌/型号/地区搜索与类型筛选并带入项目（只载入品牌/型号/小类/地区，技术参数不猜测）。
2. **合规初筛**：实时计算，结果分为可能适用 / 待补事实（回答即重算）/ 单条规则不适用（含原因）/ 待规则核验（索引级法规仅导航），并生成办理行动、材料清单与责任建议；覆盖不足显示明确缺口。
3. **HS 与税费**：HS 候选方向（非海关最终归类）；SG/AU 已核税费画像逐行输出税基、税率、税额、币种与承担方；马来西亚、德国显示变量计算式模板（税率未核实不代入数值）；内置 19 条税则知识库与贸易术语承担矩阵；条件不足时汇总保持不可用并说明阻断原因。
4. **新闻雷达（可选）**：政府官方 RSS/Atom 定时快照（北京时间约 09:17 / 17:17）；列表视图与**地图雷达视图**并存，地图支持洲/国家/产品/级别筛选、搜索、近两年窗口、每页 20 条分页，新闻卡可「加入当前项目」。
5. **千问建议**：一键调用千问 API（自带 DashScope 密钥，仅存本机浏览器）自动分析并保存；也可用手动闭环（生成任务 → 复制 → 粘贴回复）。回复严格标记「API 调用 / 人工导入」，与本地规则提示区分；输入变化后自动标「需要重新分析」。
6. **综合报告**：汇总全部结论，每条可追溯来源；打印 / 导出 PDF、导出项目 JSON（不含密钥）、报告快照与历史结果标记；本机保存（单机，非多人协作）。

## 发布（本仓库）

1. 仓库 **Settings → Pages** → Source 选 **GitHub Actions**（仅需一次）。
2. 推送 `main` 自动发布；新闻采集完成后由 `workflow_run` 自动重新发布，确保机器人提交新闻后线上实际更新。
3. 发布前 Actions 依次跑：引擎 208、税费衔接 15、第二版集成 89、第一版超集门禁、PDF 归档完整性、新加坡税费扩展、政策资料库 37、DOM 冒烟 127；任一失败即中止发布。

## 数据快照与边界

- 原始数据快照：**2026-11-04**（整合构建 2026-11-09）
- 规模：86 条条件规则；57 个叶子小类；79 条法规索引；284 条来源记录；65 行动 / 137 材料；65 条 HS 候选；19 条税种与公式；3 条贸易术语承担矩阵；SG/AU 共 33 个税费画像（其中新加坡 29 个，含二次提交新增 25 个）；政策资料库 162 条来源记录 / 161 份实体文件（178.9 MB）
- 服务档位：「支持税费测算」仅 SG×电热水壶、SG×烤面包机等已核组合；其余按「支持合规初筛 / 支持法规查询 / 产品资料待补充 / 暂不覆盖」如实展示
- 诚实声明：HS 候选 ≠ 海关最终归类；官方新闻 ≠ 已生效法规；归档文件 ≠ 全文已结构化 ≠ 规则已生效；网页阅读版 ≠ 官方法规原文；研究参数 ≠ 申报参数（充电电压≠市电电压，吸力 Pa≠功率 W）；汇总口径为「本模型已覆盖法定项目汇总」，不是完整到岸成本，关键条件不足时不按 0 处理
- 千问 API 为用户自带密钥直连（仅存本机 localStorage，页面代码、仓库与导出文件均不含密钥）
- 本工具用于合规准备与资料组织，不构成正式合规、认证、法律、税务、原产资格或海关归类结论

详见页面内「上手指南」与 [docs/04-数据来源与核验状态.md](docs/04-数据来源与核验状态.md)；二次交付明细见 [docs/R1-SECOND-DELIVERY.md](docs/R1-SECOND-DELIVERY.md)；本次合并与验收记录见 [docs/HANDOFF-REVIEW.md](docs/HANDOFF-REVIEW.md)。
