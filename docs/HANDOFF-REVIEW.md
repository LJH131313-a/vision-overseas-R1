## 二、本轮实现

### 1. 政策资料库（原“政策原文归档 · 全量 / 法规原始 PDF 与哈希校验”）

- 标题与导航统一为**政策资料库**；页面主句改为“查找法规原文与配套资料”。
- 查找维度：国家 / 地区、政策主题、适用产品、文件类型 + 关键词搜索；下拉选项**全部由清单实际数据生成**，不预设不存在的分类。
- 字段依据（不虚构）：
  - 国家：来源记录法域，缺失时取资料索引国家列；
  - 主题：该来源被哪些法规引用（法规来源关联 191 条）→ 法规监管主题（13 项）；无关联记「主题待归类」；
  - 适用产品：引用该来源的规则 → 产品小类路由（675 条）；无规则时退回法规「适用产品族」并标注“按法规适用产品族”；两者皆无记「待核实」；
  - 版本 / 日期：法规适用/生效日期或 SG 目录版本标记；缺失记「待核实」。
- 链接优先级：本地已归档 PDF → 官方 PDF 直链 → 官方网页（标注“查看官方网页”）；无本地文件时自动回退，两者皆无记入缺口。
- 排序：已归类资料优先；同一文件的不同来源编号合并显示（同哈希去重，实测 2 组重复，例如 SRC-168 与 SG-STCCED-AHTN-2022.pdf 内容相同）。
- 技术信息（SHA-256、字节、核验日期、关联法规、重复映射）收进「版本与来源详情」按需展开，不再作为主界面卖点。

### 2. 用户语言清理

- 移除用户端的“队友交付物 / 原始字节 / 构建时实测 / 哈希实测一致 / 这些是什么·不是什么 / 归档 ≠ …”等开发表述；
- 保留影响判断的事实：文件类型区分（官方法规 PDF / 官方托管原始 PDF / 网页阅读版 / 核验记录 / 产品说明书）、版本与适用日期、官方来源；明确“网页阅读版不是官方法规原文”；
- 税则知识库的“已核一般规则；交易适用仍需确认”等状态改为**使用提醒**（如“通用规则已核对，本票适用仍需按交易确认”“查不到不等于 0”“措施需在申报当日复核”）；
- 新闻与税费的重复免责说明合并为必要一句。

### 3. 研究档案页

- 删除“带入规则：只载入……”长段开发式说明，改为一句用户提示；
- 卡片上的“核验 2026-11-08”标签改为“资料 2026-11-08”，技术细节保留在确认框与详情；
- 保护行为不变：带入前确认框说明将替换哪些内容；只带入品牌 / 型号 / 小类 / 地区；技术参数不自动带入（含“充电电压不等于市电电压、吸力 Pa 不等于功率 W”提示）；重置技术事实、HS 与税费输入；researchEvidence 仍计入输入指纹，同市场同小类换型号使旧建议与快照失效。

### 4. “数据说明”→“上手指南”

- 顶栏入口、页面标题、aria 标签全部改名；新增 `renderGuide()`：
  - 项目目标一句话（帮助企业组织出海准备，不替代官方归类与专业结论）；
  - 8 节点流程卡（产品 → 目的地 → 关键事实 → 合规初筛 → HS 与税费 → 政策资料 → 千问建议 → 出海报告），纯 CSS/HTML，移动端自适应，带 `role=list` 与文字标签，不用图形代替文本；
  - “你现在的位置”与下一步建议（读取当前项目实际输入）；
  - “哪些资料会影响哪些结果”表（产品事实 / 目的地与日期 / 交易要素 / 勾选新闻与研究档案，各自影响与缺失时表现）；
  - “当前能力与边界（简明版）”：与引擎实际能力一致（可测算市场、可初筛市场、仅资料查询、汇总口径）；
  - 资料与记录入口（研究档案、政策资料库、税费覆盖矩阵、资料清单 CSV）。
- 首页四步卡片保持原样，指南不重复长文，只做入口与逻辑说明。

## 四、仍未核验的税费与资料缺口

1. **25 条新加坡画像未做官方在线核验**：沿用原仓库核验记录（此前官方税则与新加坡海关网页返回 403）。需逐项复核：六位税目与 8/10 位组合、非应税范围、零税率适用、生效日期、以及“哪些产品能生成汇总”。证据不足时应收紧输出，而不是以零补缺口。
2. **湿式与表面清洁 5 个小类**缺候选映射，不能套用吸尘器 HS；需补产品工作原理、完整商品状态、归类依据与官方税率。
3. **SRC-131.zip 仍未读取**（单文件超过 32 MiB 传输上限）；125 份索引不是资料库总数，仍有未知文件。
4. 主题待归类 64 条、适用范围待核实 85 条、类型待核实 7 条、无官方链接 4 条。
5. 网页阅读版与官方 PDF 的精确对应关系仍需逐条审核（部分官方指导页面另附不同版本的法规 PDF）。
6. 口径固定：未知条件不按 0；HS 候选 ≠ 最终归类；“本模型已覆盖法定项目汇总” ≠ 完整到岸成本；2026-12-31 是数据配置窗口而非法规失效日。
